# @magic-spells/split-text

## Purpose

Web component that splits its text into words, characters, or lines and animates each unit into view with a slide-up + fade-in stagger. Pure CSS animation; the JS just walks the DOM, wraps text nodes, and toggles a `data-state` attribute. No dependencies. Designed as a small alternative to GSAP SplitText / Splitting.js.

## Key files

- `src/split-text.js` — single class `SplitText extends HTMLElement`
- `src/split-text.css` — keyframes, custom properties, post-reveal `display:contents` reset
- `dist/` — ESM + minified UMD builds (generated by prod build)
- `demo/dist/` — built files for the demo (populated by dev mode)
- `demo/index.html` — manual testing page (served on port 3000 in dev mode); references `/dist/...` so the same paths work in dev (served from `demo/`) and on GitHub Pages (deployed from `demo/`)
- `scripts/build.mjs` — Vite + Rolldown build orchestrator (matches the @magic-spells/tarot pattern)

## Architecture

1. `connectedCallback` caches `originalHTML`, sets `aria-label` from text content, applies CSS custom properties from attributes (`--split-text-delay`, `--split-text-stagger`, etc.), and synchronously splits words or chars. Lines mode defers splitting until reveal time so it sees the actual layout.
2. Splitting walks text nodes via `TreeWalker`, replacing each text node in place with `<span class="split-text-word"><span class="split-text-word-inner">…</span></span>`. Inline markup (`<em>`, `<a>`, `<br>`) is never moved or unwrapped.
3. Each inner span has an `--i` index. CSS computes its `animation-delay` as `calc(var(--split-text-delay) + var(--i) * var(--split-text-stagger))`.
4. `trigger="visible"` (default) wires up an `IntersectionObserver`. On entry, host gets `data-state="revealing"` and the keyframe runs.
5. After animation, an `animationend` listener on the unit with the highest `--i` flips host to `data-revealed`. CSS then sets every internal wrapper to `display: contents` so text reflows naturally on resize without re-rendering. No `setTimeout` anywhere.
6. Lines mode runs `splitWords()` first, then groups consecutive word spans by their `getBoundingClientRect().top` (tolerance = `lineHeight / 2`). Every word in line N gets the same `--i`, so they animate together. No re-parenting, so nested markup survives.

## API

- Attributes: `split` (`words`/`chars`/`lines`), `delay`, `stagger`, `duration`, `easing`, `trigger` (`visible`/`load`/`manual`), `threshold`
- CSS custom properties: `--split-text-duration`, `--split-text-easing`, `--split-text-distance`, `--split-text-stagger`, `--split-text-delay`
- Methods: `reveal()`, `split()`
- Events: `split-text:start`, `split-text:complete` — both bubble, both detail `{ split, count }`

## Conventions

- `const _ = this` alias when methods reference `this` 4+ times
- Private fields with `#` prefix (`#originalHTML`, `#abortController`, `#observer`, `#initialized`, `#revealed`, `#splitMode`, `#units`)
- `AbortController` for listener cleanup; `disconnectedCallback` aborts and disconnects the observer
- Single-file source — no `src/index.js`; named export at the bottom of `src/split-text.js`
- Registration guard: `if (!customElements.get('split-text'))`
- No Shadow DOM
- `prefers-reduced-motion` short-circuits to "show immediately"
- `:not(:defined)` CSS rule prevents flash before the script runs

## Commands

- `npm run build` — production build to `dist/` (clean rebuild, minified UMD via terser, CSS via lightningcss)
- `npm run dev` — watch mode, builds to `demo/dist/`, starts Vite dev server at `http://localhost:3000`
- `npm run lint` — ESLint over `src/` and `scripts/`
- `npm run format` — Prettier write
